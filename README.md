# StewartOS

StewartOS is a private operator system for coordinating AI agents, product work, content operations, and personal workflows from a phone-first command surface.

This public repo is a sanitized showcase. It does not contain the live StewartOS workspace, private memories, credentials, cron payloads, message routing, customer data, family data, or production configuration.

## What This Shows

- The operating model behind a small AI-enabled company.
- How specialized agents can be organized by role.
- How project work, approvals, content, and engineering tasks can route through a unified command surface.
- The privacy boundary between public architecture and private operator state.

## Core Ideas

- Phone-native operations: the operator can ask for product, code, content, and review work from chat.
- Role-based agents: different agents own engineering, coordination, finance/ops, and review loops.
- Durable memory: agents write important decisions and lessons to files instead of relying on session context.
- Human approval: external actions and sensitive changes require deliberate review.
- Public/private split: source code and reusable patterns can be versioned, while secrets and personal context stay private.

## Status

This repository is intentionally lightweight. The real StewartOS system is private and contains sensitive operating context.
